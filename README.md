# Beyoncé - Morning Dew (DONK)

Site desenvolvido para apresentar informações sobre a música
"Morning Dew (DONK)", incluindo sua história, o remix e conteúdos
relacionados à faixa.

## Sobre o projeto

O projeto apresenta informações sobre a música, sua história,
o lançamento oficial e o remix, utilizando uma interface simples
e organizada.

## Tecnologias utilizadas

- HTML
- CSS

##  Estrutura do projeto

- `index.html` - página principal
- `style.css` - estilos do site
- `imagens/` - imagens utilizadas no site

##  Conteúdo

O site também apresenta vídeos relacionados à música através
de incorporação do YouTube.

##  Autora

Projeto desenvolvido para fins acadêmicos.
